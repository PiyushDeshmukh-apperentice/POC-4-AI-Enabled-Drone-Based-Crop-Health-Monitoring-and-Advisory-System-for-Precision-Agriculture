# AI-Enabled Drone-Based Crop Health Monitoring and Advisory System

## 1. Project Overview

This project aims to develop a drone-based crop health monitoring system using multispectral imagery and vegetation indices to identify potentially stressed crop regions and support agricultural decision-making.

## 2. Objectives

* Process UAV-based multispectral imagery.
* Calculate and analyse the Normalized Difference Vegetation Index (NDVI).
* Identify regions showing potential vegetation stress.
* Generate crop-health visualisations.
* Establish a foundation for crop-health classification and farmer-oriented advisories.

## 3. Dataset

The project uses UAV-based multispectral paddy crop imagery containing spectral bands such as Red, Red Edge, and Near-Infrared (NIR).

The dataset is stored on a CDAC computer. Its completeness, metadata, and availability of suitable orthomosaic products must be verified before further processing.

## 4. Proposed Workflow

1. Verify the dataset and associated metadata.
2. Inspect the available multispectral imagery.
3. Generate or validate suitable orthomosaics.
4. Verify spatial alignment between Red and NIR imagery.
5. Calculate NDVI and generate visualisations.
6. Analyse potentially stressed crop regions.
7. Develop crop-health classification and advisory features.

## 5. Current Progress

* Initial NDVI analysis and image tiling have been explored.
* A preliminary NDVI processing script is available for further validation.
* The team is transitioning towards orthomosaic-based analysis.
* Verification of the complete dataset and access arrangements are ongoing.

## 6. Next Steps

* Verify the downloaded dataset and spectral bands.
* Establish an approved method of accessing the data.
* Generate or validate multispectral orthomosaics.
* Adapt the NDVI workflow to the validated imagery.
* Establish and evaluate a suitable crop-health classification baseline.
